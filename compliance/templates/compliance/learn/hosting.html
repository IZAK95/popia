This app holds personal information too (names in requests and incidents, training attendees), so POPIA applies to it as well. Where you run it changes what you need to do.

Option A – On your own computer

  • Information stays in South Africa – no cross-border transfer for this app.
  • Nothing is exposed to the internet; only reachable from that computer.
  • You must turn on full-disk encryption (BitLocker/FileVault) and keep backups (the app writes daily backups to the backups folder – copy them to an encrypted external drive or cloud folder).
  • Only available while that computer is on.

Option B – On a Hetzner server

  • Available from anywhere, always on, protected by HTTPS, password and two-factor authentication.
  • Hetzner has no South African data centre – servers are in Germany, Finland, the USA or Singapore. Choose Germany or Finland: storing information there is a cross-border transfer under POPIA s72, justified because Hetzner is bound by the EU GDPR ("adequate protection").
  • Accept Hetzner's Data Processing Agreement in the Hetzner console and file it; keep Hetzner in your Operators register.
  • Keep the server updated and firewall only ports 22, 80 and 443 open (see the README).

If you choose Option A, delete the Hetzner entry from the Operators register.

Security built into this app

  • Mandatory two-factor authentication (authenticator app) for every sign-in.
  • Account lock-out after 5 failed password attempts.
  • HTTPS only, secure cookies, strict content-security policy, short sessions.
  • An audit log of every change.
  • Daily database backups, kept for 30 days.
